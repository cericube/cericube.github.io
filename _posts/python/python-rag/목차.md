# Python 기반 RAG 실무 개발 시리즈 (1편 ~ 9편)

## 시리즈 목표

Python 기반의 실무 RAG 시스템을 단계별로 설계하고 구현한다.

Docling을 활용한 문서 파싱과 Chunking, Gemini 및 BGE-M3 기반 Embedding, Qdrant 기반 벡터 저장과 하이브리드 검색, LangChain 기반 답변 생성 파이프라인을 구성한다.

최종적으로 검색 품질 개선, 출처 기반 답변 생성, 문서 변경 관리, 자동화 평가 및 모니터링까지 구현한다.

## 2. 최종 RAG 시스템 처리 아키텍처

## 3. 편별 입력 데이터와 산출물

| 편 | 주요 입력 | 주요 산출물 |
| --- | --- | --- |
| 1편 | 요구사항 | 시스템 설계 및 개발 환경 |
| 2편 | 원본 문서 | DoclingDocument JSON, Markdown, documents.jsonl |
| 3편 | 정규화 문서 | chunks.jsonl, Chunk Metadata |
| 4편 | Chunk 데이터 | Dense/Sparse Vector, Embedding Metadata |
| 5편 | Vector 및 Metadata | Qdrant Collection 및 검색 인덱스 |
| 6편 | Query, Collection | 검색 및 재순위화된 Chunk |
| 7편 | Retriever, Prompt | 기본 RAG Pipeline, 근거 기반 답변 |
| 8편 | 기본 RAG Pipeline | Advanced RAG Pipeline |
| 9편 | RAG Pipeline, 평가 데이터 | 평가 리포트, 회귀 테스트, 최종 시스템 |

## 4. 실무 학습 및 구현 범위

### 필수 상세 구현

- Docling 문서 파싱 및 정규화
- HybridChunker와 Contextualization
- 문서 및 Chunk 출처 메타데이터 관리
- Dense/Sparse Embedding
- Batch Embedding 및 캐싱
- Qdrant 벡터 저장 및 증분 인덱싱
- Hybrid Search, Metadata Filtering, RRF
- Reranking
- LangChain LCEL 기반 RAG Chain
- Gemini 구조화 답변 및 Citation
- Query Rewriting과 제한된 재검색
- RAG 평가 및 품질 회귀 테스트

### 개념 설명 및 간단한 실습

- Recursive Chunking
- Sliding Window Overlap
- Parent-Child Chunking
- 벡터 유사도 계산
- MRL 지원 모델의 벡터 차원 조절
- HNSW 주요 설정
- MMR
- Multi-Query Retrieval
- Contextual Compression
- Exact Cache
- nDCG 평가

### 개념 소개 및 선택적 확장

- Fine-tuning(SFT/DPO)
- Semantic Chunking
- BGE-M3 Multi-vector
- SPLADE
- Quantization
- 복잡한 Query Decomposition
- Semantic Cache
- Gemini Context Caching
- 복잡한 Self-Correction 및 Agentic RAG

고급 알고리즘의 수학적 증명, 신경망 내부 구조 분석 및 모델 학습은 본 시리즈의 필수 구현 범위에서 제외한다.

실무적으로 중요한 데이터 품질, 검색 정확도, 출처 보존, 시스템 통합, 운영 안정성 및 자동화 평가에 집중한다.
